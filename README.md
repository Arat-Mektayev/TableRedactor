# 🧮 TableRedactor

Простое веб-приложение для создания пользовательских таблиц, работы со строками и импорта/экспорта Excel.

---

## 🚀 Как запустить (Docker)

docker-compose up --build

После сборки и запуска будут доступны:

* Фронтенд: [http://localhost:3000](http://localhost:3000)
* Swagger (бекенд): [http://localhost:8000/docs](http://localhost:8000/docs)

---

## 📋 Как пользоваться

1. **Создание таблицы**
   Задайте имя и столбцы (типы: text, number, timestamp, select).

2. **Работа с таблицей**
   Откройте таблицу из списка — добавляйте, редактируйте и удаляйте строки.

3. **Импорт из Excel**
   Нажмите «Выберите файл» и загрузите .xlsx.
   ⚠️ Первая строка файла должна содержать заголовки, совпадающие с именами столбцов в таблице
   (например: title, price, 1, 2).
   Не включайте служебные поля id и created_at.

4. **Экспорт в Excel**
   Кнопка «Экспорт в Excel» выгружает таблицу, отображаемую на экране (с учётом фильтров и сортировки).

---

## 🧩 Структура проекта

backend/ — серверная часть (FastAPI): логика таблиц, импорт/экспорт, работа с PostgreSQL
frontend/ — клиентская часть (React): интерфейс, формы, таблицы, импорт/экспорт
docker-compose.yml — поднимает db, backend и frontend

---

## 💡 Подсказки

* Обязательные поля нельзя оставлять пустыми — такие строки не добавятся.
* Если импорт не добавляет строки — проверьте:

  * заголовки в Excel совпадают с именами столбцов;
  * все обязательные поля заполнены.
